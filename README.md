# 📊 Dashboard de Análise de Marketing | Power BI

## 📌 Sobre o Projeto

Projeto prático de Análise de Dados de Marketing desenvolvido com Power BI, com foco na exploração do perfil dos clientes, comportamento de consumo, desempenho das campanhas e padrões de compra.

O dashboard foi organizado em quatro visões analíticas, permitindo compreender diferentes aspectos dos dados e facilitar a interpretação dos indicadores.

O projeto utiliza dados de estudo e tem como objetivo desenvolver habilidades em Business Intelligence, análise e visualização de dados.

---

## 🎯 Objetivo

Explorar informações relacionadas aos clientes e às estratégias de marketing, identificando padrões de comportamento, características dos consumidores e indicadores que podem apoiar a tomada de decisões.

---

## 📊 Visualizações do Dashboard

### 1. Visão do Cliente

Análise do perfil dos consumidores, considerando características como escolaridade, estado civil, localização e comportamento de compra.

![Visão do Cliente](imagens/visao-cliente.png)

---

### 2. Comportamento de Compra

Exploração dos hábitos de consumo e dos canais utilizados pelos clientes, permitindo observar diferenças no comportamento de compra.

![Comportamento de Compra](imagens/comportamento-compra.png)

---

### 3. Performance das Campanhas

Análise do desempenho das campanhas de marketing, com foco na avaliação dos resultados e na identificação de oportunidades de melhoria.

![Performance das Campanhas](imagens/performance-campanhas.png)

---

### 4. Padrões de Compra

Análise dos padrões de compra por localização, permitindo comparar o comportamento dos consumidores entre diferentes países.

![Padrões de Compra](imagens/padroes-compra.png)
